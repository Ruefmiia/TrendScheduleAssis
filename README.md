# 趋势任务助手 v0.7.0

一个零依赖的 Chrome / Edge Manifest V3 扩展，用于从 X 帖子中识别趋势任务。

简要功能和安装方法请参阅 [使用说明](docs/使用说明.md)。

## 当前功能

- 读取 X 页面中用户选中的文字或当前可见帖子
- 配置一个 X 趋势账号，自动搜索其最新 `TREND SCHEDULE` 帖子
- 支持手动粘贴正文
- 识别月日或日月英文日期、活动时间、趋势开始时间，以及 GMT/UTC/BKK 时区
- 识别关键词和 `#Hashtag`
- 自动换算为北京时间（GMT+8）
- 常驻 Chrome / Edge 侧边栏，不会因点击网页而关闭
- 活动详情仅展示，一键只复制指定 Keyword 和 Hashtag
- 自动读取分阶段进度、30 秒超时和页面通信自动重试
- Keyword / Hashtag 格式校验、空格清理和可疑标签提醒
- 一键复制版本、读取阶段、帖子地址、解析结果与原始正文等调试信息
- 紧凑侧边栏布局；原始正文仅在手动处理时展开
- 顶部当前任务状态卡，优先展示正在进行或最近开始的任务
- 趋势开始前显示开始倒计时；开始后自动切换为 24 小时结束倒计时
- 趋势开始时发送一次浏览器通知，不添加直播等额外提醒
- 解析成功后自动去重保存任务，可在“任务”页切换、复制或删除
- 多趋势账号配置，可启用、停用、删除并按顺序批量刷新
- 相同日期且 Keyword 一致的跨账号帖子自动合并为一个任务，并保留全部来源账号
- 顶部三步流程明确提示“添加账号 → 识别任务 → 复制使用”
- “文案”页根据识别结果自动采用 Keyword + Hashtag 或仅 Hashtag 模式
- 内置500条语义文案，每条提供中文、英文、日语、韩语四个对应版本
- 自动匹配“通用活动”或“生日／纪念”，也可手动选择；支持随机换一批
- 本地生成辅助文案，支持编辑、逐条复制、字符计数和已使用标记，不会自动发帖
- 将最近 100 条任务保存在浏览器本机
- 缺失字段提醒与人工修改

## 本地安装

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目的 `extension` 目录，不要选择项目根目录。
5. 点击工具栏里的“趋势任务助手”，浏览器会打开常驻侧边栏。
6. 打开或切换 X 页面时，侧边栏不会自动关闭。

首次安装后，如果已经打开了 X 页面，请刷新该页面，使读取脚本生效。

## 自动读取趋势账号

1. 在“账号”页输入 `@用户名`、用户名或 X 主页链接，并添加一个或多个账号。
2. 点击顶部“识别最新任务”。
3. 扩展会在后台打开 X 的“最新”搜索页，查找该账号包含 `TREND SCHEDULE` 的帖子。
4. 若存在多条搜索结果，会按 X 提供的发布时间选择最近一条，并自动关闭后台搜索页。

该功能使用浏览器当前的 X 登录状态，不需要 API 密钥。X 可能要求用户登录；私密账号和不可见帖子无法读取。

## 已知限制

- 当前只解析帖子文字，不识别图片中的文字。
- 支持把趋势站常用的 `#️⃣ 标签文字`提示格式自动还原为普通 `#Hashtag`；复制前仍建议人工核对拼写。
- X 页面结构发生变化时，可继续使用“选中文字”或“手动粘贴”方式。

## 隐私

扩展不读取 X 密码、Cookie 或完整浏览历史。只有用户主动点击读取时，才会读取当前 X 页面中选中的文字或可见帖子。所有解析和保存均在浏览器本地完成，不会发送到服务器。

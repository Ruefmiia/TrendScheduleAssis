# 趋势任务助手使用说明

趋势任务助手是一款 Chrome / Edge 侧边栏扩展，用于读取 X 上趋势账号发布的 `TREND SCHEDULE` 帖子，并整理刷推需要的信息。

## 主要功能

### 多账号任务识别

在“账号”页添加一个或多个 X 趋势账号，然后点击顶部的“识别最新任务”。扩展会查找每个账号时间最近的趋势任务，并自动合并内容相同的任务。

### Keyword 和 Hashtag 提取

扩展会从帖子正文中识别 Keyword 和 Hashtag，并在侧边栏顶部突出显示。识别结果可以人工修改，也可以一键复制。

支持以下两种任务：

- Keyword + Hashtag
- 仅 Hashtag

### 北京时间与倒计时

帖子中的 GMT、UTC 或 BKK 时间会换算为北京时间。趋势开始前显示开始倒计时，开始后显示距离24小时结束的倒计时。

### 任务保存

识别成功的任务会保存在浏览器本地。“任务”页可以切换、复制或删除已保存任务。

### 辅助文案

“文案”页内置500个语义文案，每个文案提供中文、英文、日语和韩语版本。

扩展会自动判断“通用活动”或“生日／纪念”类型，也可以手动选择。生成结果会自动附上当前任务的 Keyword 和 Hashtag，并支持：

- 每次生成5、10或12条
- 换一批文案
- 人工编辑
- 逐条复制
- 280字符计数
- 标记已使用

文案只在浏览器本地生成，扩展不会自动发布到 X。

### 手动读取与调试

自动读取失败时，可以读取当前帖子或直接粘贴帖子正文进行解析。“复制调试信息”可以导出读取阶段、帖子地址、解析结果和原始正文，便于定位问题。

## 安装方式

1. 解压发布包。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的扩展目录。
6. 点击浏览器工具栏中的扩展图标，即可打开常驻侧边栏。

首次安装后，如果 X 页面已经打开，请刷新页面后再使用读取功能。
